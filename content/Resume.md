## 🚀 项目经历

### OpenEuler 社区贡献 — 基于 Rust 与 eBPF 的高性能节点自愈守护进程
*角色：核心开发 | 2025.06 - 2025.09*

* **异步架构设计:** 基于 **Tokio** 运行时构建异步任务池，通过 MPSC/Broadcast 通道实现“发布-订阅”模式的事件总线。解耦了监控与恢复逻辑，确保系统在高并发监控下的低开销。
* **零开销监控:** 编写 **XDP 程序** 挂载至网卡驱动层，在内核态直接解析并统计 TCP/UDP 流量特征 (PPS/BPS)，无需将数据包复制到用户态，实现了 **Zero-Overhead** 的流量静默监控。
* **高可用策略:** 设计了带 **熔断机制 (Circuit Breaker)** 和依赖协调的恢复策略，防止级联故障和资源耗尽。

### 基于 ARM64 的高性能双内核隔离与资源调度框架 (实验室项目)
*角色：核心开发 | 2025.07 - 2025.12*

* **内核隔离:** 通过 `isolcpus` 与 `nohz_full` 将多核资源划分为控制域与实时域，结合中断亲和性绑定技术，旁路标准 Linux CFS 调度器干扰，实现关键任务 **<200µs** 的确定性调度延迟。
* **核间通信:** 在实时核 (Cobalt) 中实现高优先级调度器，通过基于 **共享内存** 与 **无锁环形队列** 的异构核间 IPC 协议驱动内核模块代理发送指令。
* **eBPF 追踪:** 编写 **eBPF** 程序挂载至内核调度追踪点，以零系统调用开销实时捕获高频进程生命周期事件，解决多核并发下的资源竞争。

### 异构环境下的高性能虚拟化网络子系统实现 (毕业设计)
*涉及技术：Jailhouse, VirtIO, RTEMS, OpenAMP*

* **虚拟网络驱动:** 在基于 **Jailhouse Hypervisor** 的嵌入式多核 SoC 平台上，基于标准化的 **VirtIO** 协议栈，设计并实现一套用于核间通信的虚拟网络驱动。
* **前端驱动开发:** 在 RTEMS 环境下开发了无 PCI 依赖 (MMIO-based) 的 **virtio-net Frontend Driver**。
* **零拷贝机制:** 设计了基于 **OpenAMP / Libmetal** 的共享内存管理层，实现了从 RTEMS mbuf 到 VirtIO vring 的数据包 **零拷贝 (Zero-Copy)** 或高效拷贝路径。
