# 什么是RDMA技术
**RDMA**（Remote Direct Memory Access）技术可以从名字看出来和**DMA**的有着千丝万缕的关系。
- DMA意思是我们的外设，在读写的过程中，数据的拷贝复制不依赖于CPU就可以进行。
- 我们在DPDK中曾经大量分析网卡通过IOMMU映射到DPDK所管理的内存区域的操作过程。我们称之为”零拷贝“其实并不是真正的数据完全不拷贝，而是CPU对拷贝时间几乎零参与，所以叫做零拷贝。
- 但是在DPDK中，存在一个缺陷，就是大部分场景需要一个CPU一直进行polling才能实现较高性能；而RDMA虽然也提供了Polling模式，但是大多数情境下依然是使用的触发机制来完成工作。
- RDMA可以实现真正意义上的**端到端零拷贝**，发送方应用直接指定内存地址，接收方应用提供内存地址，网卡直接把数据从机器A的内存搬到机器B的内存。
